## 1. 一句话定位

**"Synthea 之于医疗 = 本项目之于油气"**（调研报告 §4.4/§5/§6.1）：不做第 N+1 个通用表格合成器，做油气领域专用的合成数据工作台，第一主攻调研确认的框架级空白——**油田生产时序 + 设备传感器 + 钻井参数**合成。

## 2. 背景与问题

三条现状断言（注源调研报告）：

1. **通用框架成熟但不懂油气**：SDV（3.6k★）/ mostlyai（802★）/ synthcity（685★）等有完整的"schema→变换→生成→评估"流水线，但没有油气 schema、单位制、物理约束的概念（调研报告 §2/§4.4）。
2. **油气物理引擎能产真物理但没有 ML 封装**：OPM Flow、MRST、devito、neqsim 均活跃维护，可批量扫参产出物理上必然成立的数据，但没有面向 ML 的 schema 化输出、噪声注入与评估闭环（调研报告 §4.1/§4.4）。
3. **两件事之间缺的那一层无人做**：GitHub 上不存在任何框架级"油田生产时序/设备传感器/钻井参数"合成数据项目，搜索到的同类最高仅 2★（调研报告 §4.4，2026-09-25 检索核实）。

## 3. 目标与非目标

### 3.1 目标（M3 内可达）

- G1 领域 schema 层：井 / 井筒 / 传感器通道 / 生产台账的实体模型与单位制声明（自研，格式参考 SDV metadata 与 Synthea 模块参数，调研报告 §5.1）。
- G2 物理打底产数：油藏模拟器进程外适配器 + 扫参编排，产出"物理上必然成立"的生产时序骨架，再叠加真实工况扰动（噪声/漂移/缺测/坏点）。
- G3 评估闸门三族：质量（SDMetrics 式）+ 隐私（anonymeter 三类攻击）+ **物理一致性自研**（物质平衡、传感器量程/采样率合法性、递减率范围）——第三族无现成开源，是差异化卖点（调研报告 §3.3/§6.2 L5）。
- G4 Tracer bullet："一条命令生成一口合成井"贯穿全链路。

### 3.2 非目标（红线）

- 不自研油藏/地震/工艺物理引擎，只集成现成的（调研报告 §4.1）。
- LLM 不产数值时序——只做文档层叙述化（完井报告/班报/工单），且接受 schema 校验回流（调研报告 §3.2/§5.5）。
- 合成数据禁止用于储量申报、生产决策等真实业务（README 已声明，须同步进输出元数据）。
- 不做通用表格合成器，不与 SDV/mostlyai 正面竞争。

## 4. 技术路线（分层混合，注源调研报告 §6.2）

| 层 | 干什么 | 选型（均已核实 license） |
|---|---|---|
| L0 领域 schema | 实体/单位制/场景配方（recipe）声明 | 自研；格式参考 SDV metadata / Synthea 模块参数 |
| L1 规则+随机打底 | 实体字典（井名/设备型号/故障代码）+ 字段填充 | faker / mimesis（均 MIT），扩展油气 locale |
| L2 物理引擎产数 | 生产时序骨架、PVT/工艺参数 | OPM Flow / MRST（**GPL-3.0，独立进程集成**）、neqsim（Apache-2.0） |
| L3 统计/深度生成补分布 | 学习残差分布、注入真实感噪声 | fg-data-synthetic（原 ydata，MIT）、mostlyai / synthcity（Apache-2.0）；扩散思路参考 tab-ddpm |
| L4 LLM 文档层 | 结构化事实 → 班报/工单叙述化 | distilabel（Apache-2.0）管线模式，Magpie 无提示采样可借鉴 |
| L5 评估闸门 | 质量 + 隐私 + 物理一致性 | SDMetrics（MIT）+ anonymeter + **自研物理一致性指标** |

技术路线为"建议值"，依赖层的可插拔是硬要求：任一生成器/指标都应能替换（调研报告 §5.2 synthcity 插件化模式的借鉴）。

## 5. License 与合规策略

（注源调研报告 §6.3，截至 2026-09-25 核实）

- **本体 Apache-2.0**（与 mostlyai / synthcity / devito 同族，方便下游企业采用）。
- **GPL-3.0 组件**（OPM Flow、MRST、DuMux、openDARTS、ert）：只以命令行/独立进程交互，不链接源码、不二次分发其代码。
- **BUSL-1.1**（SDV、CTGAN）：仅内部实验，不作对外服务内核。
- **真实数据锚点的上游合规**：Volve（Equinor Open Data Licence）、FORCE 2020（NLOD 2.0，Zenodo 直接下载）、Norne（随 OPM/opm-data 分发）——这些是真实数据，其条款对"用它们做分布先验/评估基准产出的合成数据"如何传导，**需读原始条款后确认**（开放问题 Q5）。
