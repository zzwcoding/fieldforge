# MISSION —— fieldforge 学习目标

**一句话**：完全理解 fieldforge 这个油气合成数据工作台——数据怎么造出来、怎么被质检、怎么被闸门守着、怎么通过两个 HTTP 面对外服务，以及每一层"为什么这么设计"。

**验收标准**（学完的标志，三条缺一不可）：
1. 能不看资料，用自己的话讲清"一条合成数据的一生"（配方→生成→质检→入湖→问数）；
2. 亲手在云上跑通全部关键链路（生成/质检/查询/拒答/溯源），并做过每一步的捣乱实验；
3. 场景闯关题全部通过（每场景 3 题，答错的进学习日志补考）。

**边界**：学 fieldforge（生成器）+ 云上两个 HTTP 面 + 部署栈。不学 tpa-data-plane 内部实现（那是另一仓另一课，但会讲清两者的交界文件契约）。

**学习方式约定**（Owner 已定）：服务与软件全部使用云上已部署的（8.163.33.135），本地不搭环境；场景导览模式（项目已建成），只读红线——学习期间不改 fieldforge 生产代码，发现 bug 记学习日志转票。
